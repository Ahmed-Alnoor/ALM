# Radikal (brand font)

Put the licensed Radikal web fonts here with these exact names and the page will use them automatically:

- Radikal-Thin.woff2 (200)
- Radikal-Light.woff2 (300)
- Radikal-Regular.woff2 (400)
- Radikal-Medium.woff2 (500)
- Radikal-Bold.woff2 (700)

Until they are added, the page falls back to Outfit (Google Fonts), the closest free match.
